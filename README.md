# AI Resume Analyzer

A powerful AI-driven tool to analyze resumes, extract key information, and match them with job descriptions.

## Project Structure

- **frontend/**: React/Next.js application for the user interface.
- **backend/**: FastAPI/Node.js server for AI processing and API.
- **database/**: Database schemas and migrations.
- **docs/**: Project documentation and API specifications.
- **deployment/**: Docker configurations and CI/CD pipelines.
- **tests/**: Unit and integration tests.

## Features

- AI-powered skill extraction
- Experience evaluation
- Match score with job descriptions
- Recommendation system for improvements
